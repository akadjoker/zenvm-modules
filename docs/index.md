# Documentation Index

zenvm-modules carries the native modules, runners, demos and — as of this
copy — the language docs and tutorials that used to live in the zenvm core
repository. The core VM itself (compiler, VM, plain `zen` CLI) is
[zenvm](https://github.com/akadjoker/zenvm), consumed here as a git
submodule at `vendor/zenvm`.
